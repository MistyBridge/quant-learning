# quant-learning

我的量化策略学习打卡仓库，记录从入门到进阶的量化学习全过程。

## 开发环境

- **平台**: [JoinQuant 聚宽量化平台](https://www.joinquant.com/)
- **语言**: Python
- **运行方式**: 在聚宽官网编写代码并回测

## 项目结构

```
quant-learning/
├── strategies/
│   ├── 入门策略/
│   │   └── 双均线策略.py       # 5日/20日均线金叉死叉策略
│   └── 进阶策略/
│       ├── 烟蒂股策略_v1_原版.py        # 小市值+高股息, 等权满仓（基线, top_n=10）
│       ├── 烟蒂股策略_v2_正向凯莉.py    # 同选股 + 正向分数凯莉仓位
│       ├── 烟蒂股策略_v3_逆向凯莉.py    # 同选股 + 逆向加减仓(越跌越加仓/涨超减仓,最低50%仓)
│       ├── 烟蒂股策略_v4_凯莉动态平衡.py # 同选股 + 凯莉/波动率/回撤三重风控 + 带内再平衡
│       ├── 烟蒂股策略_v5_等权满仓_分散20.py # 同选股 + top_n=20 等权满仓(纯分散, 无凯莉/风控层)
│       ├── 烟蒂股策略_v6_等权满仓_集中5.py  # 同选股 + top_n=5 等权满仓(更集中, 无凯莉/风控层)
│       └── 烟蒂股策略_v7_因子避险版.py  # 同选股 + 小微盘指数120日线风险开关(标准差定比例)

```

## 学习路线

1. **入门** - 双均线策略、单均线突破、MACD 策略
2. **进阶** - 多因子选股、动量策略、均值回归
3. **高级** - 机器学习、高频策略、风险控制

## 聚宽平台使用说明

1. 注册 [聚宽账号](https://www.joinquant.com/)
2. 进入"我的策略" -> 新建策略
3. 将 `strategies/` 下的代码复制到聚宽在线编辑器
4. 设置回测参数（起止日期、初始资金等）-> 运行回测
