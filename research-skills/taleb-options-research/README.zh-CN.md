# 塔勒布期权研究

中文 | [English](README.md)

这是一个用于 Codex 的期权研究 Skill。它把许哲和 Nassim Nicholas Taleb
启发的期权想法，整理成可以检查、可以反驳的研究方案。你可以用它分析具体合约、比较期权组合、写清楚转仓规则，或者判断一个策略还缺哪些数据。

它提供的是研究方法，不是交易信号。结论可能是某个候选值得继续测试，也可能是证据不足，或者当前应当 `NO_TRADE`（不交易）。

当前版本：**1.1.0**

## 它能帮你做什么？

| 你的目的 | 你需要提供 | Skill 会给出 | 对行情数据的要求 |
|---|---|---|---|
| 核对许哲、塔勒布或已审阅资料究竟支持什么 | 一个问题、观点或资料范围 | 带来源定位的解释，并列出限制、冲突和未解决问题 | 不需要 |
| 分析一个具体期权 | 合约身份、报价时间、买卖价、合约条款和相关账户约束 | 合约核对；到期损益；路径、价格、流动性、保证金、行权和指派风险；条件性结论 | 由你提供当前快照 |
| 比较多腿组合与简单替代方案 | 每一条腿、可执行报价、拟定数量，以及风险或权利金预算 | 损益和路径对比、总成本、隐藏亏损区、否决条件，以及 `NO_TRADE` 对照 | 由你提供同一时点的快照 |
| 把一个想法写成可测试策略 | 交易假设、市场范围、可用品种、约束条件，以及持有或转仓逻辑 | 明确的腿、参数、入场/再平衡/退出规则、数据要求、基准、风险限制和反证测试 | 初步设计不需要；进入市场测试前需要 |
| 把转仓或“收割—重建”思路写清楚 | 当前持仓、观察频率、触发条件、分支动作、停止条件和成本假设 | 状态机、完整现金账、歧义分支、失败条件和所需数据 | 取决于规则；测试时通常需要历史数据和时点快照 |
| 从你提供的期权链中筛选候选 | 某一时点的期权链、可执行报价、合约细节，以及流动性和风险约束 | 合格与被淘汰的合约、条件性排序、每项理由，以及可能的 `NO_TRADE` | 由你提供期权链；Skill 不会自行抓取 |
| 审核回测、模拟、候选清单或模拟观察报告 | 结果、方法、数据范围、成本假设，最好还有完整搜索记录 | 检查选择偏差、估计不稳定、对少数极端日的依赖、遗漏成本、保证金路径和基准是否完整 | 不需要实时数据，但必须能看到相关测试资料 |
| 设计未来的美股或币圈期权扫描器 | 目标市场、交易场所、账户约束和研究目标 | 字段、过滤器、排序规则、否决门槛、快照要求和输出格式 | 不需要；这里只设计扫描器，不运行扫描 |

### 它可以帮我选期权吗？

可以，但能力取决于你提供的数据：

| 现有数据 | Skill 能做到什么 |
|---|---|
| 没有市场数据 | 解释资料、设计结构、推导损益并定义测试；不能判断当前合约是否价格合适、能否成交 |
| 你提供期权链或报价快照 | 只在这批合约中分析和排序，并遵守你声明的约束；结果仍可能是 `NO_TRADE` |
| 实时期权链、历史数据和数据接口 | 理论上可以做持续的全市场监控，但本版本**不包含**这些接口和扫描器 |

因此，它可以给出有依据的**研究候选**，也可以在明确假设下比较组合；但它不会自动找出全市场“最好的”实时期权，不会给出个性化下单指令，也不会代你提交订单。

## 一份分析会包含什么？

实际深度取决于问题和数据。完整结果通常包括：

| 结果部分 | 回答的问题 |
|---|---|
| 结论 | 哪些检查通过、哪些失败、当前研究状态，以及最大的已知风险 |
| 合约定义 | 每条腿的方向、数量、行权价、到期日、乘数、行权方式、结算、币种和未确定字段 |
| 损益与路径 | 到期损益、肩部亏损区，以及标的价格、时间、波动率曲面、流动性和保证金变化下的盯市表现 |
| 价格与生存 | 权利金、持有成本、价差、深度、费用、融资、指派、保证金、部分成交、强制平仓和账户清算风险 |
| 对照 | 在同一预算下，与更简单的期权结构及 `NO_TRADE` 比较 |
| 证据 | 来源 ID、定位、公式和推导，并区分原始资料、待校准参数、压力假设和未知项 |
| 下一步测试 | 缺失数据、反证条件，以及什么结果允许进入或必须退出下一研究阶段 |

如果你需要，结果还可以整理成可由程序验证的 **StrategySpec**。通过
Schema 只表示研究规格的内部结构完整，不表示策略已经通过模拟，更不表示可以实盘。

## 使用示例

安装后，在自然语言请求中提到 `$taleb-options-research` 即可。例如：

- 根据我附上的报价和合约信息，分析这张 SPY 看跌期权。列出权利金风险、到期前的路径风险、流动性问题和否决条件。
- 在相同权利金预算下，比较这个买入宽跨式、四腿翅膀结构和不交易。
- 检查这个“暴涨暴跌都能赚钱”的说法，看看是否隐藏了肩部亏损，或者依赖不现实的成交价格。
- 把这些转仓笔记改写成明确的状态、触发条件、现金变动和停止条件。
- 审核这份回测。大部分收益来自三个极端交易日，请检查估计是否稳定、成本是否完整，以及搜索过程是否污染了样本外区间。
- 定义一个覆盖美股期权或币圈期权的扫描器应收集哪些字段，又应设置哪些淘汰规则。

合约身份、报价时间、可执行价格、账户约束和研究目的写得越清楚，输出就能越具体。

## 它目前不会做什么

- 自行抓取实时期权链或历史行情。
- 定时监控美股或币圈的全部可交易期权。
- 连接嘉信、IBKR、OKX、Binance 或其他券商、交易所。
- 在缺少必要数据和外部研究环境时运行可信回测。
- 提交真实或模拟订单、索取账户密钥，或者代管组合。
- 保证盈利，或者把书中的示例直接当成生产参数。

实时监控、券商和交易所接入、回测与模拟交易，属于后续
`evidence-based-options-strategy-v1` 平台项目。本版本提供的是这套平台可以调用的研究逻辑和输出契约。

## 这套方法怎样判断一个想法

1. **先把合约写清楚。** 每一条腿都要明确方向、数量、行权价、到期日、行权方式、结算、乘数和币种。
2. **先看能否生存，再看收益。** 在收益排序之前，先检查账户清算、保证金扩张、跳空、指派和强制平仓。
3. **检查整条路径。** 到期损益图不够；还要分析标的价格、时间、波动率曲面、流动性和保证金状态的共同变化。
4. **把全部成本算进去。** 权利金、持有和融资成本、价差、深度、费用、对冲、部分成交和清算成本都要进入比较。
5. **与诚实的基准比较。** 复杂组合应当在相同预算下与简单结构和 `NO_TRADE` 对照。
6. **主动寻找反例。** 结果必须列出未知项、缺失数据、压力情景、样本外要求，以及推翻策略的条件。

当研究依赖尾部推断时，Skill 还会检查：现有样本是否足以支持所用统计量、结果是否由少数极端值主导、不同概率口径是否混在一起，以及超过历史最大值后会发生什么。

## 覆盖的策略结构

| 研究类别 | 重点检查内容 |
|---|---|
| 同到期翅膀结构（`F1`） | 买入外侧看跌/看涨、卖出中间期权，并检查两个肩部亏损区和卖方 Gamma 的保证金风险 |
| 跨到期翅膀结构（`F2`） | 日历或对角组合，包括远期波动率、偏斜、长期权剩余生命周期和可执行转仓 |
| 动态收割与重建（`F3`） | 带版本的转仓政策，包括触发器、分支动作、现金账、陈旧报价和停止状态 |
| 直接或复制的复合期权（`F4`） | 严格区分上市、场外、动态复制和研究意义上的“期权的期权” |
| 简单基准（`B1`–`B5`） | 买入看跌、买入看涨、买入双尾、保护性看跌，以及一个卖波动率反例 |
| 不交易（`F5`） | 避免的成本与风险、机会成本、缺失数据，以及重新启动研究的条件 |

书籍或讨论中的配置比例、价内外程度、到期日和压力点只作为研究资料。Skill 不会把它们悄悄变成默认交易设置。

## 安装

克隆仓库，再把可安装的 Skill 目录复制到 Codex skills 目录。

macOS/Linux：

```bash
git clone https://github.com/trigeek/taleb-options-research-skill.git
cp -R taleb-options-research-skill/skill/taleb-options-research ~/.codex/skills/
```

Windows PowerShell：

```powershell
git clone https://github.com/trigeek/taleb-options-research-skill.git
Copy-Item -Recurse .\taleb-options-research-skill\skill\taleb-options-research "$HOME\.codex\skills\"
```

安装后，重启或刷新 Codex 的 Skill 发现。可安装目录是
[`skill/taleb-options-research`](skill/taleb-options-research/)；仓库 README
不进入运行时 Skill。

## StrategySpec 验证

验证一份研究记录：

```bash
python skill/taleb-options-research/scripts/validate_strategy_spec.py artifact.json --mode single
```

验证器需要 Python `jsonschema` 包。组合模式可使用 `--mode portfolio`。所有随包规格均要求 `execution_authority=false`。

## 来源与证据

公开版本包含项目自行编写的摘要和结构化研究记录，不包含原始资料的复制件。

| 等级 | 含义 |
|---|---|
| `D` | 带定位的直接来源记录 |
| `B` | 有来源支持的解释 |
| `C` | 跨来源综合 |
| `A` | 独立推导或复算 |
| `U` | 未解决、互相冲突或缺失 |

遇到已知冲突时，发布版会保留冲突，不会靠猜测补齐。例如，许哲 E43
中 replacement put 的买卖方向仍标记为 `U`。

1.1.0 版本包括：

- 422 条主张摘要、233 条公式记录、245 条不含原图的视觉元数据，以及
  183 条研究规则；
- 对塔勒布 *Statistical Consequences of Fat Tails* 第三版（2025）的逐章审阅，来源 ID 为 `SCOFT-3E-2025`；
- 渐近前、矩可用性、极端值集中度、单一大跳跃、超历史最大值、联合尾部、离散对冲和多重检验检查；
- 带条件的幂律相对定价研究，以及受尾部约束的杠铃结构规格；
- 向后兼容、可选的 `fat_tail_robustness` StrategySpec 区块。

已审阅资料见
[公开来源清单](skill/taleb-options-research/references/source-inventory.release.md)。
原书、音频、逐字稿、OCR、页面图片和私有复核清单都不包含在公开仓库中。

### Public Core 与自备资料

安装后的 Skill 默认使用发布版登记表，以 `PUBLIC_CORE` 模式工作。这种模式会说明：当前会话没有直接回查原始页。

如果你合法持有某个版本，可以用离线 BYOS 工具建立索引和本地复核缓存：

```bash
python skill/taleb-options-research/scripts/index_local_sources.py \
  SCOFT-3E-2025=/path/to/your/lawful-third-edition.pdf \
  --output /path/to/local-index.json

python skill/taleb-options-research/scripts/verify_source_manifest.py \
  /path/to/local-index.json

python skill/taleb-options-research/scripts/build_local_evidence_cache.py \
  /path/to/local-index.json \
  --evidence-root /path/outside/the/repository
```

这些工具只在本地运行，不会搜索主目录、下载资料或上传内容。本地哈希、OCR、页码映射和复核记录必须放在本仓库和已安装 Skill 之外。
